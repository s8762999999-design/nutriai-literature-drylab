# NutriAI 文獻評析與 Dry Lab 實驗工作台

版本：**v1.0**  
網站：https://s8762999999-design.github.io/nutriai-literature-drylab/

這是一個繁體中文單頁互動工作台，包含方法學指引、五篇研究的整理、比較矩陣、Dry Lab 假說，以及提示詞架構模擬器。

## 使用

直接以瀏覽器開啟 index.html。頁面使用 Tailwind CSS、Chart.js 與 Google Fonts 的 CDN 資源，互動圖表和字型需要網路連線。

## 部署

GitHub Pages 設定為 main 分支的 / (root)，網站入口為 index.html。

## 內容範圍

本次部署沿用提供的 HTML 內容，只加入 v1.0 版本標示與頁尾標記；文獻敘述、數值及引用未在本次部署工作中逐項獨立複核。模擬器所呈現的預估值是頁面內建的合成示例，不應視為模型實測結果。
