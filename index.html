實證方法學基礎

一、 AI 基準測試與公衛營養文獻評讀比較架構

依據 Cochrane Handbook 第六版、SWiM（無統合分析之敘述性綜合指引）及統計方法學，確立統一的評估標準與數據解讀邊界。

1

統一萃取與敘述性綜合 (SWiM)

當研究間的任務型態（影像迴歸 vs 文本關係抽取）、模型架構與黃金標準高度異質時，強行合併數據會產生嚴重的統計偏誤。SWiM 指引要求建立統一萃取表，依據輸入資料、分析任務、參照標準與量測分母進行分群，進行結構化敘述比較。

PRISMA 僅為報告指引，不可代替品質評讀
2

相關性、誤差與一致性之區分

Spearman $\rho$ / Pearson $r$：僅反映趨勢變化，即使數據全數低估 50% 仍可得高相關。
MAE / MedAPE：反映絕對誤差距離。
Lin's CCC / Bland-Altman：衡量估算值是否圍繞在 $y=x$ 絕對對角線上，為臨床替代人工黃金標準的唯一依據。

高相關 $\neq$ 數值估算準確
3

分類表現 vs 幻覺率與事實性

NLP 任務中，F1-Score / Precision / Recall 適用於離散類別預測（如食物分類或 NER）。分類改善不可延伸推論為熱量估算或健康效益改善。幻覺率（Hallucination）需透過特定事實性（Factuality）覆核或正負向邏輯檢驗評估。

分類精準 $\neq$ 無幻覺或數值精確
⚠️
AI 基準測試套用傳統醫學指引的關鍵微調： 傳統 Cochrane 指引多針對 RCT 臨床試驗設計。然而在 AI 研究中，即使測試集資料來自 RCT（如 Zhou 2026），AI 演算法之間的效能比較本身仍屬於觀察性運算實驗（Benchmark Test），不可誤認為演算法本身經隨機對照驗證。評估重點應在於：測試集是否嚴格隔離防洩漏、提示詞與模型是否為獨立控制變更，以及黃金標準是否經專家雙盲覆核。

期刊: Am J Clin Nutr (AJCN, 2025) | JIF: 7.1-7.9 [已核實]
DOI: 10.1016/j.ajcnut.2025.10.013
任務與輸入: 食物照片 + 文字名稱輔助 $\rightarrow$ 秤重級別營養估計

1. 核心問題與繁體中文摘要

核心問題：在真實自由生活情境下，客製化多模態 GPT-4o 聊天機器人結合「食物照片」與「使用者提供文字名稱」，能否達到與營養師秤重紀錄（WFR）相當的飲食評估準確率？
摘要整理：研究收集 57 名年輕成人 171 天共 714 張食物照片，比較 4 種 AI 設定。結果顯示具備食物名稱輔助的客製模型（DBFN）表現最佳，多數營養素落入等效區間。作者結論指出標準化提示詞與文字輔助能顯著提升準確率，但仍需專家監督。

2. 痛點與問題鏈解析

既有限制： 純影像 AI 常因遮蔽與 3D 深度缺失，導致複雜菜餚辨識與份量估算出現巨大誤差。
本篇解法： 客製化 System Prompt 並要求使用者主動輸入食物名稱。
實驗驗證： 在自由生活情境中與嚴格的秤重飲食紀錄（WFR）進行 Lin's CCC 與 Bland-Altman 比對。
改善結果： 大幅收斂食物辨識誤差，確立文字輔助能降低視覺推理難度。

3. 真正研究貢獻定位

【原文結果直接支持】具名客製模型（DBFN）之 Lin's CCC 達到 0.662 至 0.863，顯著優於純視覺無文字輔助模型 [AJCN 2025]。

【分析推論】此研究證明 VLM 本質上更適合做為「營養計算機」而非「純視覺食物辨識器」。提供食物名稱改變了任務難度，將「辨識+估算」退化為「已知種類下之體積估算」。

關鍵數據表現：輸入模式對 Lin's CCC 一致性之影響

展示文字名稱輔助如何顯著提升模型與秤重紀錄（WFR）的一致性

碩士研究用途： 雖然此文獻針對影像，但其使用嚴謹秤重法（WFR）建立黃金標準，以及運用 Bland-Altman / Lin's CCC 的統計框架，可直接複製至你未來評估文獻萃取一致性之實驗中。
期刊: JAMIA (2025) | JIF: 7.1 [已核實]
DOI: 10.1093/jamia/ocaf054
任務與輸入: 醫學文獻摘要/全文 $\rightarrow$ 飲食-微生物體 15種實體/13種關係萃取

1. 核心問題與繁體中文摘要

核心問題：如何建構標準化語料庫並評估微調模型與通用大語言模型（LLM）從飲食-微生物體科學文獻中萃取實體與複雜因果關係的能力？
摘要整理：開發 DiMB-RE 語料庫（165 篇摘要、30 篇全文段落），定義 15 種實體與 13 種關係。微調 PL-Marker 在 NER 達 F1 0.800，但端到端關係抽取（RE）僅 0.445。未微調之 GPT-4o（Zero-shot）表現更低。結論指明領域文獻資訊萃取極具挑戰，跨句關係判定是主要瓶頸。

2. 痛點與問題鏈解析

既有限制： 飲食與微生物體關聯知識分散於龐大非結構化文獻中，且缺乏專用標註本體與基準。
本篇解法： 建立 DiMB-RE 標註規範，並評估 PL-Marker 與 GPT-4o (Zero-shot / One-shot)。
實驗驗證： 專家人工雙重標註做為黃金標準，計算 NER、RE 之 Precision/Recall/F1 與 Factuality。
改善結果： 殘酷揭露最先進 LLM 在無微調或無強大 Prompt 輔助下，關係抽取能力嚴重不足。

3. 真正研究貢獻定位（與你的碩士題目極高度相關）

【作者主張與數據支持】建立領域最大標註語料庫，證明特定微調模型（PL-Marker F1=0.458）優於 GPT-4o Zero-shot (F1=0.377) 與 One-shot (F1=0.398) [JAMIA 2025]。

【分析推論】此研究清楚劃分了「關鍵字抓取 (NER)」與「邏輯關係推理 (RE)」的難度鴻溝，為你的提示詞實驗奠定基礎—— Prompt 工程必須重點突破「關係推理」而非單純實體擷取。

任務與輸入: 食物照片 $\rightarrow$ 多模型與 Prompt 架構 (Visual vs CoT) 營養估算比較

1. 核心問題與繁體中文摘要

核心問題：在跨資料集條件下，不同的大語言模型（如 Claude Sonnet, GPT-4）與提示詞架構（Visual Zero-shot vs CoT）對照片營養估算的性價比與誤差有何影響？
摘要整理：測試 NutriImage、SNAPMe、JBFD 三個資料集。結果顯示 Claude Sonnet 具最佳成本效益。CoT 思維鏈在部分模型可微幅降低誤差，但對「鹽分當量」等隱藏營養素，所有模型與 Prompt 之 MedAPE 均高達 34%-64%。結論指明提示詞無法克服物理視覺盲點。

2. 痛點與問題鏈解析

既有限制： 既有研究多依賴單一資料集或模型，缺乏將 Prompt 架構設計為獨立控制變因的評估。
本篇解法： 設計 2x3 交叉比較（Visual vs CoT Prompt $\times$ 3 種 LLM 模型）。
實驗驗證： 跨三個公開照片資料集計算 MAE 與 MedAPE 絕對百分比誤差。
改善結果： 釐清 CoT 的邊際效益，並揭露隱藏營養素估算的先天物理極限。

3. 真正研究貢獻定位

【原文結果直接支持】首次系統性將 CoT 提示詞納入多資料集營養估估算比較；證實鹽分估算 MedAPE 高達 58.2% [Nutrients 2026]。

【分析推論與邊界】提供重要邊界結果（Negative Result）：CoT 提示詞能優化邏輯推理，但無法「無中生有」憑空創造照片中不可見的物理調味數據。

任務與輸入: 標準餐點照片 (114張) $\rightarrow$ ChatGPT-4 重量與 16種營養素定量評估

1. 核心問題與繁體中文摘要

核心問題：未經特殊提示詞工程的通用 ChatGPT-4，在面對標準化餐點照片時，估計食物種類與 16 種營養素重量的能力為何？
摘要整理：使用 114 張包含小、中、大三種份量的餐點照片。結果模型在食物分類精準度極高（Precision 93%），且小份量重量估算良好；但對中大份量產生嚴重系統性低估，10 種營養素一致性差。結論指明通用 LLM 缺乏幾何體積放縮能力。

2. 痛點與問題鏈解析

既有限制： 缺乏針對原生 ChatGPT 進行餐點照片重量估算的大規模定量基準數據。
本篇解法： 製備標準化三種份量餐點，直接進行橫斷面基準評估。
實驗驗證： 比對實驗室秤重黃金標準，採用 Wilcoxon 檢定、Spearman $\rho$ 與 ICC。
改善結果： 釐清分類能力（強）與迴歸連續數估算（弱）的重大落差。

3. 真正研究貢獻與偏誤剖析

【原文結果直接支持】食物辨識 Precision 達 93%，但大份量餐點重量平均低估達 41.8% [Nutrients 2025]。

【分析推論】此研究深刻揭示了 LLM 的「典型份量偏誤（Regression to the Mean）」。LLM 傾向輸出預設的典型克數，無法從 2D 照片進行 3D 空間體積估算。

期刊: JAMIA (2026正式版, 預印本為 2025) | JIF: 7.1 [已核實]
DOI: 10.1093/jamia/ocag003
任務與輸入: 臨床 RCT 自由飲食文字紀錄 $\rightarrow$ NutriRAG 架構自動分類與特徵提取

1. 核心問題與繁體中文摘要

核心問題：如何利用檢索增強生成（RAG）解決病患在自由生活下撰寫的雜亂、口語化飲食紀錄文字的自動化分類問題？
摘要整理：採集 12 週臨床 RCT 試驗數據，開發 NutriRAG 框架檢索相似標註範例做為提示詞上下文。結果 GPT-4 + RAG 之 Micro F1 達 82.24，顯著高於無 RAG 的 73.84 及傳統 MLP。結論證實 RAG 是提升臨床文本分類精準度與穩定度之關鍵。

2. 痛點與問題鏈解析

既有限制： 真實世界病患紀錄充滿錯字與口語描述，傳統 NLP 模型分類準確率極低。
本篇解法： 導入 RAG 架構，從歷史標註庫檢索高相關範例進行 In-context learning。
實驗驗證： 於真實 RCT 飲食紀錄集比對有/無 RAG 之 Precision/Recall/Micro F1。
改善結果： Micro F1 提升近 9 個百分點，並成功分析出限時進食（TRE）組別的行為差異。

3. 真正研究貢獻與警語標記

【原文數據支持】RAG 介入使 GPT-4 分類 Micro F1 由 73.84% 提升至 82.24% [JAMIA 2026]。

【重要注意與警語】資料雖來自 RCT 試驗，但 AI 演算法比較本身為觀察性測試，不可誤稱為 RCT 證據。此外，文本分類改善不可推論為熱量估算或幻覺率改善。

四、 核心問題解答與 Dry Lab 實驗假說設計

針對題目「提示詞架構 (Zero-shot / CoT / RAG) 對 LLM 公衛營養文獻審查與萃取品質之影響」進一步提煉可檢驗假說。

1. AI 解決了什麼？

高精準度的語意理解與基礎分類（如 O'Hara 食物辨識 Precision 93%）、文字模糊紀錄的標準歸類（Zhou NutriRAG F1 82.2%）與實體關鍵字擷取（NER）。

2. 哪些瓶頸反覆出現？

物理維度缺失（2D 轉 3D 體積崩潰）、隱藏資訊無能為力（透視調味料）、以及文獻中跨句子複雜因果關係（RE）與邏輯幻覺（Hong F1 < 0.46）。

3. 哪一篇對你的題目最直接？

Hong et al. (2025) (DiMB-RE)。因為它是唯一專注於科學文獻關係萃取，且建立完整本體論與事實性（Factuality，即幻覺反指標）黃金資料庫的研究。

可檢驗的 Dry Lab 實驗假說提案 (三個擬定變量設計)

假說一：RAG 架構對幻覺率（事實性錯誤）之抑制效果 Hypothesis H1
自變項 (IV): 提示詞架構 (Zero-shot vs. RAG 檢索增強)
依變項 (DV): 事實性錯誤率 (Factuality Error Rate / 幻覺率)
固定條件: 相同開源 LLM (Llama-3-70B)、相同 100 篇公衛文獻摘要
參照標準: 2 位營養師雙盲標註之黃金文獻抽取表
預期判讀: RAG 檢索上下文能有效約束 LLM 生成，使其錯誤率顯著低於 Zero-shot。
假說二：Chain-of-Thought (CoT) 對跨句關係抽取 F1 之提升 Hypothesis H2
自變項 (IV): 提示詞架構 (Standard Prompt vs. CoT 思維鏈)
依變項 (DV): 關係抽取 (Relation Extraction) F1-Score / Recall
固定條件: 限制為具跨句關聯之複雜營養介入文獻；模型統一採 GPT-4o
參照標準: DiMB-RE 關係分類規範 (增加, 抑制, 影響)
預期判讀: 要求「先列實體再推導邏輯」的 CoT 能顯著提升跨句關聯 RE F1 分數。
假說三：重複執行內部一致性（Intra-model Consistency）對比 Hypothesis H3
自變項 (IV): 提示詞架構 (Zero-shot vs. CoT vs. RAG)
依變項 (DV): 5 次重複呼叫之 Jaccard 相似度 / Fleiss' Kappa
固定條件: 設定 LLM Temperature = 0.7（維持適度隨機性），測試 50 篇文獻
參照標準: 模型自身多次輸出之交叉對比 (驗證演算法穩定度)
預期判讀: RAG 強制 Context 約束能壓制高 Temp 隨機性，一致性顯著高於 Zero-shot。
